```
NEXT_PUBLIC_SUPABASE_ANON_KEY=<anon>
META_APP_ID=<your meta app>
META_APP_SECRET=<secret>
META_VERIFY_TOKEN=<8+ chars>
META_REDIRECT_URI=https://<omni-web-staging-host>/settings/channels/callback
```

`TOKEN_ENCRYPTION_KEY` / `SERVICE_M2M_KEY` are auto-generated by Blueprint.

After first deploy, set `META_REDIRECT_URI` to the real web URL and redeploy api.
